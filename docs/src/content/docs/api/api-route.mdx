export const metadata = { title: "createHandler", description: "Universal adapter factory that creates Web Standard handlers for proxy-mode requests from any framework." }

## Import

```ts
import { createHandler } from "@noverax/nexus"
```

## Signature

`createHandler` takes your source definitions and returns `handleGet` and `handlePost` functions that work with Web Standard `Request`/`Response`.

```ts
const { handleGet, handlePost } = createHandler(sources)
```

## Parameters

### sources

A record of API source definitions created with `defineApi()`.

```ts
import { sources } from "@/api"

const { handleGet, handlePost } = createHandler(sources)
```

## Return Type

```ts
type AdapterHandler = {
  handleGet: (request: Request) => Promise<Response>
  handlePost: (request: Request) => Promise<Response>
}
```

## Framework Adapters

Each framework has a dedicated adapter package that wraps `createHandler`:

### Next.js

```ts title="app/api/request/route.ts"
import { apiRoute } from "@noverax/nexus-next"
import { sources } from "@/api"

export const { GET, POST } = apiRoute(sources)
```

### Express

```ts title="server.ts"
import { nexusHandler } from "@noverax/nexus-express"
import { sources } from "./api"

app.use("/api/request", nexusHandler(sources))
```

### Hono

```ts title="server.ts"
import { nexusHandler } from "@noverax/nexus-hono"
import { sources } from "./api"

app.all("/api/request/*", nexusHandler(sources))
```

### Fastify

```ts title="server.ts"
import { nexusPlugin } from "@noverax/nexus-fastify"
import { sources } from "./api"

fastify.register(nexusPlugin, {
  sources,
  prefix: "/api/request",
})
```

### NestJS

```ts title="nexus.middleware.ts"
import { nexusMiddleware } from "@noverax/nexus-nestjs"
import { sources } from "./api"

export class NexusMiddleware {
  use = nexusMiddleware(sources)
}
```

### Nuxt

```ts title="server/api/request/[...].ts"
import { nexusHandler } from "@noverax/nexus-nuxt"
import { sources } from "~/api"

export default nexusHandler(sources)
```

## Request Flow

```bash
# POST request flow:
# 1. Validate Origin header (CSRF protection)
# 2. Parse Content-Type (JSON or FormData)
# 3. Extract: source, group, method, variables, options
# 4. Call executeRequest(sources, payload, context)
# 5. Return response

# GET request flow:
# 1. Parse query params: _s (source), _g (group), _m (method), _o (options)
# 2. Remaining params become variables
# 3. Call executeRequest(sources, payload, context)
# 4. Return response
```

## Security

### Origin Validation

The handler validates the `Origin` header against the request URL. Mismatched origins return `403`:

```ts
// Built-in origin check — prevents CSRF
const origin = request.headers.get("origin")
if (!origin || new URL(request.url).origin !== origin) {
  return Response.json(
    { success: false, message: "Origin mismatch" },
    { status: 403 }
  )
}
```

### Header Whitelisting

Only safe headers are forwarded from the browser to the backend. Extend the whitelist with `allowedHeaders` in your `defineApi()` options.

<Callout variant="tip" title="Web Standard">
`createHandler` works with any runtime that supports the Web Standard `Request`/`Response` API — Node.js, Deno, Bun, Cloudflare Workers, and more. Framework adapters handle the mapping from framework-specific types.
</Callout>
