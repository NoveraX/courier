## Step 1: Define your API

Create a file with your API definition using `defineApi`, `defineGroup`, and `endpoint`:

```ts title="api/sources.ts"
import { defineApi, defineGroup, endpoint } from "@noverax/nexus/define"

type User = { id: string; name: string; email: string }

const users = defineGroup({
  prefix: "users",
  endpoints: {
    getAll:  endpoint<User[]>()((http) => http.get()),
    getById: endpoint<User, { id: string }>()((http, vars) => http.get(":id", vars)),
    create:  endpoint<User, { name: string; email: string }>()((http, vars) => http.post("", vars)),
    update:  endpoint<User, { id: string; name: string }>()((http, vars) => http.put(":id", vars)),
    remove:  endpoint<null, { id: string }>()((http, vars) => http.del(":id", vars)),
  },
})

const api = defineApi({
  baseURL: process.env.API_URL!,
  groups: { users },
})

export const sources = { api }
export type Sources = typeof sources
```

<Callout variant="info" title="Path parameters">
The `:id` syntax automatically extracts `id` from variables and inserts it into the URL. Remaining variables become query params (GET) or body (POST/PUT/PATCH).
</Callout>

## Step 2: Set up the caller

Choose the mode that fits your use case:

**Direct mode** — call your backend from any runtime:

```ts title="lib/caller.ts"
import { createCaller } from "@noverax/nexus"
import { sources } from "@/api/sources"

export const call = createCaller(sources)
```

**Proxy mode** — browser requests go through your server (hides API keys, bypasses CORS):

```ts title="lib/caller.ts"
import { createProxyCaller } from "@noverax/nexus"
import type { Sources } from "@/api/sources"

export const call = createProxyCaller<Sources>({ proxyUrl: "/api/request" })
```

**React Query** — hooks with full type inference:

```ts title="lib/caller.ts"
import { createQueryCaller } from "@noverax/nexus-query"
import type { Sources } from "@/api/sources"

export const { useQuery, useMutation, caller } = createQueryCaller<Sources>()
```

<Callout variant="tip" title="Use both modes together">
Most apps use proxy/React Query for client-side and direct mode for server-side. Both share the same source definitions.
</Callout>

## Step 3: Use it

**With React Query:**

```tsx title="app/users/page.tsx"
"use client"
import { useQuery, useMutation } from "@/lib/caller"

export default function UsersPage() {
  const { data: users, isLoading } = useQuery("api", "users:getAll")
  //      ^? User[]

  const { mutate } = useMutation("api", "users:create", {
    onSuccess: (user) => console.log("Created:", user.name),
    //                                           ^? string
  })

  if (isLoading) return <p>Loading...</p>

  return (
    <div>
      <ul>
        {users?.map((u) => <li key={u.id}>{u.name} — {u.email}</li>)}
      </ul>
      <button onClick={() => mutate({ name: "Jane", email: "jane@test.com" })}>
        Add User
      </button>
    </div>
  )
}
```

**Direct mode (server-side):**

```tsx title="app/dashboard/page.tsx"
import { call } from "@/lib/caller"

export default async function DashboardPage() {
  const users = await call("api")("users:getAll")
  //    ^? User[]

  return <ul>{users.map((u) => <li key={u.id}>{u.name}</li>)}</ul>
}
```

**Vanilla TypeScript (no framework):**

```ts
import { createCaller } from "@noverax/nexus"
import { sources } from "./api/sources"

const call = createCaller(sources)

const users = await call("api")("users:getAll")
const user = await call("api")("users:getById", { id: "1" })
```

## What's happening under the hood

When you call `call("api")("users:getById", { id: "5" })`:

1. Nexus parses `"users:getById"` into group `users` and method `getById`
2. The `:id` path parameter is extracted from variables → `GET /users/5`
3. Middleware chain runs (retry, auth, logging, etc.)
4. Schema validation runs (if configured)
5. The typed response flows back to your code

In proxy mode, step 2-5 happen on your server. The browser only sees `/api/request`.
