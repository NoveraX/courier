**@noverax/nexus** is an HTTP client library designed specifically for Next.js applications. It provides end-to-end type safety from your API definition to your React components — without code generation, schema files, or a custom backend.

You define your API as TypeScript classes with typed methods. Nexus infers request and response types automatically, giving you autocomplete for method names, variables, and response shapes.

## How It Works

Define your API structure using `Datasource` and `EndpointGroup` classes. Each method declares its response type and variables type using the `Endpoint<Response, Variables>` generic:

```ts title="api/sources.ts"
import { Datasource, EndpointGroup, Endpoint } from "@noverax/nexus/datasource"

type User = { id: number; name: string; email: string }

class Users extends EndpointGroup {
  constructor() {
    super({ prefix: "users" })
  }

  getAll: Endpoint<User[]> = ({ get }) => get()
  getById: Endpoint<User, { id: number }> = ({ get }) => get(":id")
  create: Endpoint<User, { name: string; email: string }> = ({ post }) => post()
}

class MyApi extends Datasource<{ users: Users }> {
  constructor() {
    super({ baseURL: "https://api.example.com", groups: { users: new Users() } })
  }
}
```

Then use it in your components with full type inference:

```ts title="app/page.tsx"
// React Query integration — fully typed
const { data, isLoading } = useQuery("myApi", "users:getAll")
//      ^? User[]

const { mutate } = useMutation("myApi", "users:create")
mutate({ name: "Jane", email: "jane@example.com" })
//      ^? { name: string; email: string } — auto-inferred
```

## Two Transport Modes

Nexus supports two modes for executing requests, both sharing the same API definition:

- **Proxy Mode** — browser sends a POST to your Next.js API route, which forwards the request to your backend. Hides secrets, bypasses CORS, and forwards cookies automatically.
- **Direct Mode** — server-side code (RSC, Server Actions) calls the backend directly with no proxy hop. Same type safety, zero overhead.

<Callout variant="tip" title="Same definitions, two modes">
You write your `Datasource` and `EndpointGroup` classes once. Both `createClientRequest` (proxy) and `createDirectRequest` (direct) consume them with identical type inference.
</Callout>

## Core Philosophy

- **Type safety without codegen** — no generated files, no build steps. TypeScript classes are the source of truth.
- **Zero boilerplate** — define a method signature and Nexus handles serialization, path parameters, headers, and error wrapping.
- **Next.js-first** — App Router, Server Components, Server Actions, and API Routes are first-class citizens.
- **Works with any REST backend** — no custom server required. Connect to Express, FastAPI, Rails, or any HTTP API.
