export const metadata = { title: "createProxyCaller", description: "Factory function that creates a typed, curried caller for proxy-mode HTTP calls from the browser.", mode: "proxy" }

## Import

```ts
import { createProxyCaller } from "@noverax/nexus"
```

## Signature

`createProxyCaller` accepts an optional defaults object and returns a `TypedClient`. The generic parameter `T` is your `typeof api` type — it enables full type inference for endpoint groups, methods, variables, and response types.

```ts
const caller = createProxyCaller<typeof api>(defaults?)
```

## Parameters

### ProxyCallerDefaults

All fields are optional.

```ts
type ProxyCallerDefaults = {
  proxyUrl?: string
  timeout?: number
  credentials?: RequestCredentials
  headers?: Record<string, string>
  onError?: (error: HTTPError) => void | Promise<void>
  onSuccess?: (data: unknown) => void | Promise<void>
}
```

- `proxyUrl` — full URL path to the proxy endpoint. Defaults to `"/api/request"`.
- `timeout` — request timeout in milliseconds.
- `credentials` — cookie handling policy. Defaults to `"include"`.
- `headers` — default headers merged into every request.
- `onError` — global error handler invoked on every `HTTPError`.
- `onSuccess` — global success handler invoked on every successful response.

## Return Type

Returns a `TypedClient<T>` — a typed object with dot-notation access to your API groups and endpoints:

1. **Group access** — `caller.users` — accesses the endpoint group.
2. **Endpoint execution** — `caller.users.getAll(variables?, options?)` — executes an endpoint with optional variables and options.

```ts
type TypedClient<T> = {
  [Group in keyof T["groups"]]: {
    [Method in keyof T["groups"][Group]]: (
      variables?: Variables,
      options?: CallOptions,
    ) => Promise<Response>
  }
}
```

## Basic Usage

```ts title="lib/query.ts"
import { createProxyCaller } from "@noverax/nexus"
import type { api } from "@/api"

const caller = createProxyCaller<typeof api>({
  timeout: 10000,
  credentials: "include",
})

// Dot-notation: caller.group.method(variables?, options?)
const users = await caller.users.getAll()
const user = await caller.users.getById({ id: "123" })
```

## Configuring Defaults

```ts title="lib/query.ts"
const caller = createProxyCaller<typeof api>({
  // Proxy endpoint URL (default: "/api/request")
  proxyUrl: "/api/nexus",

  // Request timeout in milliseconds
  timeout: 15000,

  // Cookie handling (default: "include")
  credentials: "include",

  // Default headers for every request
  headers: {
    "X-App-Version": "1.0.0",
    "Accept-Language": "en",
  },

  // Global error handler
  onError: (error) => {
    if (error.status === 401) {
      window.location.href = "/login"
    }
  },

  // Global success handler
  onSuccess: (data) => {
    console.log("Request succeeded:", data)
  },
})
```

## Per-Request Options

Pass `CallOptions` as the second argument after variables:

```ts
const user = await caller.users.getById({ id: "123" }, {
  timeout: 5000,
  signal: controller.signal,
  method: "GET",  // Use GET for cacheable reads
})
```

## Upload Progress

Pass `onUploadProgress` to track file upload progress. When set, Nexus uses `XMLHttpRequest` for real network-level progress tracking.

```ts
const result = await caller.files.upload(formData, {
  onUploadProgress: (progress) => {
    console.log(`${Math.round(progress.percent * 100)}%`)
  },
})
```

<Callout variant="info" title="XHR Transport">
When `onUploadProgress` is set, Nexus uses `XMLHttpRequest` instead of `fetch` to provide real network-level progress tracking on both HTTP/1.1 and HTTP/2.
</Callout>

## GET Proxy Mode

By default, proxy requests use POST. Set `method: "GET"` for cacheable reads — variables are encoded as query parameters:

```ts
// GET proxy: cacheable, works with CDN and browser cache
const users = await caller.users.getAll(undefined, { method: "GET" })

// POST proxy: default, used for mutations and complex payloads
const user = await caller.users.create({ name: "Jane" })
```
