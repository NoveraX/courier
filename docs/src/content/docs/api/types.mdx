## Overview

All TypeScript types used across the Nexus library, organized by category.

## Caller Types

### CallerFn

The caller function type used internally by `createCaller`, `createProxyCaller`, and `createQueryCaller`. The public API exposes a `TypedClient` with dot-notation access.

```ts
type CallerFn<T extends Record<string, any>, D extends boolean = false> = <
  K extends keyof T,
  RD extends boolean = false,
>(
  source: K,
  options?: CallOptions<RD>,
) => <
  Q extends EndpointKey<T[K]>,
  M extends ResolveEndpoint<T[K], Q>,
  R = ExtractResponse<M>,
>(
  ...arguments_: EndpointArguments<Q, M, D>
) => EndpointResult<RD, R>

// D = false → Proxy mode → returns Promise<R>
// D = true  → Direct mode → returns Promise<Partial<HttpResponse<R>>>
```

### CallerDefaults

Options for `createCaller`.

```ts
type CallerDefaults = {
  timeout?: number
  headers?: Record<string, string>
  context?: Context
  onError?: (error: HTTPError) => void | Promise<void>
  onSuccess?: (data: unknown) => void | Promise<void>
}
```

### ProxyCallerDefaults

Options for `createProxyCaller` and `createQueryCaller`.

```ts
type ProxyCallerDefaults = {
  proxyUrl?: string
  timeout?: number
  credentials?: RequestCredentials
  headers?: Record<string, string>
  onError?: (error: HTTPError) => void | Promise<void>
  onSuccess?: (data: unknown) => void | Promise<void>
}
```

## Endpoint Definition Types

### Endpoint

The type of an endpoint function. Generic over response type `R` and variables type `V`.

```ts
type Endpoint<R, V = undefined> = (
  methods: HttpMethods,
  variables: V,
) => HttpResponse<R> | Promise<HttpResponse<R>>
```

### HttpMethods

The object your endpoint definitions receive with HTTP method functions.

```ts
type HttpMethods = {
  [K in HttpMethod]: <T = unknown>(
    ...arguments_: MethodParameters<K>
  ) => Promise<HttpResponse<T>>
}

type HttpMethod = "get" | "post" | "put" | "patch" | "del" | "head"
```

## Response Types

### HttpResponse

```ts
type HttpResponse<T = unknown> = {
  status: number    // HTTP status code
  headers: Headers  // Response headers
  data: T           // Parsed response body
}
```

### SuccessResponse

```ts
type SuccessResponse<D = unknown> = {
  success: true
  data: D
}
```

## Options Types

### CallOptions

Per-request options passed when calling an endpoint.

```ts
type CallOptions<R extends boolean = false> = SimpleOptions & {
  rawData?: R
  forwardVariables?: boolean
  stream?: boolean
  method?: "GET" | "POST"
  onUploadProgress?: (progress: UploadProgress) => void
}
```

### UploadProgress

```ts
type UploadProgress = {
  percent: number           // 0 to 1
  transferredBytes: number
  totalBytes: number
}
```

### MethodParameters

```ts
type MethodParameters<T extends HttpMethod> = T extends "head"
  ? [url?: string, options?: MethodOptions<T>]
  : [url?: string, variables?: Record<string, unknown>, options?: MethodOptions<T>]
```

## Query Utility Types

Internal utility types that power the type inference engine:

```ts
// Extracts all valid endpoint keys for a source
type EndpointKey<T> = FunctionKeys<T> | GroupedEndpoints<Groups<T>>
// Result: "methodName" | "group:methodName"

// Resolves the Endpoint type from an endpoint key
type ResolveEndpoint<T, Q> = /* resolves to Endpoint<R, V> */

// Extracts response type from an Endpoint
type ExtractResponse<M extends Endpoint<any, any>> =
  M extends Endpoint<infer R, any> ? R : unknown

// Extracts variables type from an Endpoint
type ExtractVariables<M extends Endpoint<any, any>> =
  M extends Endpoint<any, infer V> ? V : unknown
```

<Callout variant="info" title="Type inference">
These utility types are what make Nexus fully type-safe. When you call `caller.users.getById({ id })`, TypeScript resolves the group, endpoint, variables, and response types automatically.
</Callout>

## React Query Types

```ts
type QueryOptions<R, V> = WithVariables<V> &
  Omit<UseQueryOptions<R, HTTPError, R, QueryKey>, "queryKey" | "queryFn"> & {
    requestOptions?: CallOptions
  }

type MutationOptions<R, V> = Omit<
  UseMutationOptions<R, HTTPError, MutationVariables<V>>,
  "mutationFn"
> & {
  requestOptions?: CallOptions
}

type MutationVariables<V> = [V] extends [undefined]
  ? void
  : {} extends V ? void | V : V

type WithVariables<V> = [V] extends [undefined]
  ? { variables?: undefined }
  : {} extends V
    ? { variables?: V }
    : { variables: V }
```
