The core package has zero runtime dependencies and works in any JavaScript runtime with `fetch`.

## Framework adapters

Install the adapter for your server framework. Each adapter is a thin wrapper around `createHandler` — see the [Server Handler](/docs/proxy-mode/api-route) docs for details.

| Framework | Package | Export |
|-----------|---------|--------|
| **Next.js** | `@noverax/nexus-next` | `apiRoute`, `createAction` |
| **Nuxt / Nitro / h3** | `@noverax/nexus-nuxt` | `nexusHandler` |
| **Express** | `@noverax/nexus-express` | `nexusHandler` |
| **Hono** | `@noverax/nexus-hono` | `nexusHandler` |
| **Fastify** | `@noverax/nexus-fastify` | `nexusPlugin` |
| **NestJS** | `@noverax/nexus-nestjs` | `nexusMiddleware` |

## React Query integration

For React apps, add the query package for type-safe hooks (`useQuery`, `useMutation`, `useSuspenseQuery`, `useInfiniteQuery`):

```bash
npm install @noverax/nexus-react @tanstack/react-query
```

<Callout variant="info" title="Install only what you use">
All framework packages and integrations are optional. The core `@noverax/nexus` package works standalone for direct API calls from any runtime.
</Callout>

## TypeScript configuration

Nexus ships type declarations. Enable strict mode for the best type inference:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "target": "ESNext",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true
  }
}
```

## Environment variables

Add your backend API URL as a server-side environment variable:

```bash title=".env.local"
# Your backend API URL (server-side only)
API_URL=http://localhost:4000
```

This is used in your `defineApi` call. In proxy mode, the browser never sees this URL — requests go through your server's proxy route.
