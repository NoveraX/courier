export const metadata = { title: "createClientRequest", description: "Factory function that creates a typed, curried request function for proxy-mode HTTP calls from the browser." }

## Import

```ts
import { createClientRequest } from "@noverax/nexus"
```

## Signature

`createClientRequest` accepts an optional `ClientRequestDefaults` object and returns a curried `RequestFn` function. The generic parameter `T` is your `Sources` type — it enables full type inference for source names, query names, variables, and response types.

```ts
import { createClientRequest } from "@noverax/nexus"

const request = createClientRequest<Sources>(defaults?)
```

## Parameters

### ClientRequestDefaults

All fields are optional. When omitted, sensible defaults are used.

```ts
type ClientRequestDefaults = {
  routePath?: string
  timeout?: number
  credentials?: RequestCredentials
  headers?: Record<string, string>
  onError?: (error: HTTPError) => void | Promise<void>
  onSuccess?: (data: unknown) => void | Promise<void>
}
```

- `routePath` — the API route segment. Requests are sent to `/api/{routePath}`. Defaults to `process.env.NEXT_PUBLIC_REQUEST_PAGE` or `"request"`.
- `timeout` — request timeout in milliseconds. Applied to every request unless overridden per-call.
- `credentials` — cookie handling policy. Defaults to `"include"` (always send cookies cross-origin).
- `headers` — default headers merged into every request.
- `onError` — global error handler invoked on every `HTTPError`. Useful for centralized auth redirects or logging.
- `onSuccess` — global success handler invoked on every successful response.

## Return Type

Returns a `RequestFn<T>` — a curried function with two invocation levels:

1. **Source selection** — `request(source, options?)` — picks a data source and optional per-request settings.
2. **Query execution** — `request(source)(query, variables?)` — executes a method with optional variables.

```ts
type RequestFn<T> = <K extends keyof T>(
  source: K,
  options?: CallOptions,
) => <Q extends EndpointKey<T[K]>>(
  queryRequest: Q,
  variables?: Variables,
) => Promise<Response>
```

## Basic Usage

```ts title="lib/request.ts"
import { createClientRequest } from "@noverax/nexus"
import type { Sources } from "@/api/sources"

// Create with defaults
const request = createClientRequest<Sources>({
  timeout: 10000,
  credentials: "include",
})

// Usage: request(source)(query, variables?)
const users = await request("api")("users:getAll")
const user = await request("api")("users:getById", { id: "123" })
```

## Configuring Defaults

```ts title="lib/request.ts"
const request = createClientRequest<Sources>({
  // API route name — maps to /api/{routePath}
  // Default: process.env.NEXT_PUBLIC_REQUEST_PAGE || "request"
  routePath: "nexus",

  // Request timeout in milliseconds
  timeout: 15000,

  // Cookie/credential handling
  // Default: "include" (always send cookies cross-origin)
  credentials: "include",

  // Default headers for every request
  headers: {
    "X-App-Version": "1.0.0",
    "Accept-Language": "en",
  },

  // Global error handler — called on every HTTPError
  onError: (error) => {
    if (error.status === 401) {
      redirectToLogin()
    }
  },

  // Global success handler — called on every successful response
  onSuccess: (data) => {
    console.log("Request succeeded:", data)
  },
})
```

## Per-Request Options

The second argument to the source selector accepts `CallOptions` — per-call overrides for timeout, caching, streaming, abort signals, and more.

```ts
// Per-request options via the second argument of source selection
const user = await request("api", {
  timeout: 5000,
  rawData: true,       // Return { status, headers, data } instead of just data
  stream: true,        // Return ReadableStream response
  signal: controller.signal,  // AbortController signal
  cache: "no-store",   // Next.js fetch cache option
})("users:getById", { id: "123" })
```

## Upload Progress

Pass `onUploadProgress` to track file upload progress. Nexus automatically detects `FormData` and sends it as `multipart/form-data`.

```ts
// File upload with progress tracking
const result = await request("api", {
  onUploadProgress: (progress) => {
    console.log(`${Math.round(progress.percent * 100)}%`)
    console.log(`${progress.transferredBytes} / ${progress.totalBytes}`)
  },
})("files:upload", formData)
```

```ts
// FormData is automatically detected and sent as multipart/form-data
const formData = new FormData()
formData.append("file", fileInput.files[0])
formData.append("name", "document.pdf")

const result = await request("api")("files:upload", formData)
```

<Callout variant="info" title="XHR Transport">
When `onUploadProgress` is set, Nexus uses `XMLHttpRequest` instead of `fetch` to provide real network-level progress tracking on both HTTP/1.1 and HTTP/2.
</Callout>

## How It Works

Under the hood, `createClientRequest` sends a `POST` to your Next.js API route (`/api/request` by default) using `ky`. The request body contains the source name, group, query, variables, and options — the server handler (`apiRoute`) then resolves the method and executes it against the backend.
