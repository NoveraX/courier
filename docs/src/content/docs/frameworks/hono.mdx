The `@noverax/nexus-hono` adapter lets you host the Nexus proxy route on any Hono-supported runtime: Node.js, Bun, Deno, and Cloudflare Workers.

## Installation

```bash
npm install @noverax/nexus @noverax/nexus-hono hono
```

## Define your API sources

```ts title="lib/sources.ts"
import { defineApi, defineGroup, endpoint } from "@noverax/nexus/define"

type User = { id: number; name: string; email: string }

const users = defineGroup({
  prefix: "users",
  endpoints: {
    getAll: endpoint<User[]>()(({ get }) => get()),
    getById: endpoint<User, { id: number }>()(({ get }) => get(":id")),
    create: endpoint<User, { name: string; email: string }>()(
      ({ post }) => post()
    ),
  },
})

export const api = defineApi({
  baseURL: process.env.API_URL ?? "http://localhost:4000",
  groups: { users },
})

export const sources = { myApi: api }
```

## Setup

Create a Hono app with the Nexus handler:

```ts title="src/index.ts"
import { Hono } from "hono"
import { cors } from "hono/cors"
import { nexusHandler } from "@noverax/nexus-hono"
import { sources } from "./lib/sources"

const app = new Hono()

app.use("/api/*", cors())

app.all("/api/request", nexusHandler(sources))

export default app
```

That is all you need. The `nexusHandler` function returns a standard Hono handler that processes incoming Nexus proxy requests and forwards them to your backend.

## Runtime-specific entry points

### Node.js

```ts title="src/index.ts"
import { serve } from "@hono/node-server"
import { Hono } from "hono"
import { cors } from "hono/cors"
import { nexusHandler } from "@noverax/nexus-hono"
import { sources } from "./lib/sources"

const app = new Hono()

app.use("/api/*", cors())
app.all("/api/request", nexusHandler(sources))

serve({ fetch: app.fetch, port: 3001 }, (info) => {
  console.log(`Server running on http://localhost:${info.port}`)
})
```

### Bun

```ts title="src/index.ts"
import { Hono } from "hono"
import { cors } from "hono/cors"
import { nexusHandler } from "@noverax/nexus-hono"
import { sources } from "./lib/sources"

const app = new Hono()

app.use("/api/*", cors())
app.all("/api/request", nexusHandler(sources))

export default {
  port: 3001,
  fetch: app.fetch,
}
```

### Deno

```ts title="src/index.ts"
import { Hono } from "hono"
import { cors } from "hono/cors"
import { nexusHandler } from "@noverax/nexus-hono"
import { sources } from "./lib/sources.ts"

const app = new Hono()

app.use("/api/*", cors())
app.all("/api/request", nexusHandler(sources))

Deno.serve({ port: 3001 }, app.fetch)
```

### Cloudflare Workers

```ts title="src/index.ts"
import { Hono } from "hono"
import { cors } from "hono/cors"
import { nexusHandler } from "@noverax/nexus-hono"
import { sources } from "./lib/sources"

const app = new Hono()

app.use("/api/*", cors())
app.all("/api/request", nexusHandler(sources))

export default app
```

<Callout variant="info" title="Same handler, any runtime">
The `nexusHandler` function uses the standard Web API `Request`/`Response` objects, so it works identically across all Hono-supported runtimes with zero configuration changes.
</Callout>

## Adding other routes

The Nexus handler only handles the proxy route. You can add any other Hono routes alongside it:

```ts title="src/index.ts"
import { Hono } from "hono"
import { cors } from "hono/cors"
import { nexusHandler } from "@noverax/nexus-hono"
import { sources } from "./lib/sources"

const app = new Hono()

app.use("/api/*", cors())

// Nexus proxy route
app.all("/api/request", nexusHandler(sources))

// Your own routes
app.get("/health", (c) => c.json({ status: "ok" }))

app.get("/api/stats", (c) => {
  return c.json({ uptime: process.uptime() })
})

export default app
```

## Studio integration & `appOrigin` <a id="studio-app-origin"></a>

If you wire your Hono app into Studio via `instrumentServer`, pass `appOrigin` so the Playground proxy executor can resolve relative `proxyPath.{sse,ws}` values into absolute URLs. Node `fetch` and `WebSocket` reject relative URLs, so this is required for Studio Playground proxy mode whenever your `proxyPath` does not already include a full `http(s)://...` prefix.

```ts title="src/index.ts"
import { serve } from "@hono/node-server"
import { Hono } from "hono"
import { nexusHandler } from "@noverax/nexus-hono"
import { instrumentServer } from "@noverax/nexus-studio-core"
import { sources } from "./lib/sources"

const app = new Hono()
app.all("/api/request", nexusHandler(sources))

if (process.env.NODE_ENV !== "production") {
  instrumentServer({
    sources,
    appOrigin: "http://localhost:3001",  // this server's own URL
  })
}

serve({ fetch: app.fetch, port: 3001 })
```

Alternatively, set `NEXUS_APP_URL` instead of passing `appOrigin` explicitly:

```bash
NEXUS_APP_URL=http://localhost:3001 node src/index.js
```

<Callout variant="warn" title="Edge runtimes">
`instrumentServer` only runs on Node-compatible runtimes (Bun also works). Cloudflare Workers and Deno do not currently host Studio's Socket.IO bridge — for those targets the Studio integration is a no-op and Playground proxy mode is unavailable. Use the [standalone server](/docs/deployment/standalone-server) for development against edge deployments.
</Callout>

<Callout variant="warn" title="No magic default">
There is no `localhost:3001` auto-fallback. If `appOrigin` is missing, clicking "Subscribe" on an SSE/WS endpoint in Studio Playground proxy mode throws `ConfigurationError("APP_ORIGIN_NOT_CONFIGURED")` with a pointer back to this section. The correct value depends on your runtime — custom port, Docker host, HTTPS, reverse proxy — and a wrong guess would silently route requests to nowhere.
</Callout>

## Client-side setup

On the client, point your caller to this server's proxy URL. Choose the guide for your frontend:

- [React (Vite / CRA)](/docs/frameworks/react) — `createProxyQueryCaller` with React Query hooks
- [Vue](/docs/frameworks/vue) — `createProxyCaller` with composables
- [Next.js](/docs/frameworks/nextjs) — full-stack with `apiRoute` and `createProxyQueryCaller`
- [Nuxt](/docs/frameworks/nuxt) — full-stack with `nexusHandler` and `createProxyCaller`

```ts title="lib/caller.ts"
import { createProxyCaller } from "@noverax/nexus"
import type { api } from "../shared/sources"

export const caller = createProxyCaller<typeof api>({
  proxyPath: { http: "http://localhost:3001/api/request" },
})
```
