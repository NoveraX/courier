## Overview

By default, Nexus returns only the parsed response body (JSON or text). When you need to inspect the HTTP status code or read response headers, enable raw data mode by passing `{ rawData: true }` in the request options.

Raw data mode changes the return type from `Promise<T>` to `Promise<{ status, headers, data }>`:

```ts
// Normal mode (default) — returns just the data
const users = await request("myApi")("users:getAll")
// users = [{ id: 1, name: "Jane" }, ...]

// Raw data mode — returns status, headers, and data
const response = await request("myApi", { rawData: true })("users:getAll")
// response = {
//   status: 200,
//   headers: Headers { "content-type": "application/json", ... },
//   data: [{ id: 1, name: "Jane" }, ...],
// }
```

## Enabling raw data mode

Pass `rawData: true` as the second argument to your request function. This is set per-request, not per-source, so you can use it only where you need the extra metadata:

<Callout variant="info" title="Per-request option">
`rawData` is a `MethodsInstanceOptions` field. It does not go in `BaseOptions` on the source — you enable it on individual requests where you need status or headers.
</Callout>

## Checking status codes

Use raw data mode when your API uses different status codes to communicate different outcomes. For example, distinguishing between "created" (201) and "already exists" (200):

```ts title="lib/api-helpers.ts"
async function createUser(data: { name: string; email: string }) {
  const response = await request("myApi", { rawData: true })("users:create", data)

  if (response.status === 201) {
    console.log("User created:", response.data)
    return { created: true, user: response.data }
  }

  if (response.status === 200) {
    console.log("User already existed:", response.data)
    return { created: false, user: response.data }
  }

  return { created: false, user: null }
}
```

## Reading response headers

Many APIs include useful metadata in response headers. Raw data mode gives you access to the full `Headers` object:

### Pagination headers

```ts title="lib/api-helpers.ts"
async function fetchPaginatedUsers(page: number) {
  const response = await request("myApi", { rawData: true })("users:getAll", {
    page,
    limit: 20,
  })

  // Read pagination info from response headers
  const totalCount = Number(response.headers?.get("X-Total-Count") ?? 0)
  const linkHeader = response.headers?.get("Link") ?? ""

  return {
    users: response.data,
    total: totalCount,
    hasMore: page * 20 < totalCount,
  }
}
```

### Rate-limit headers

```ts title="lib/api-helpers.ts"
async function safeRequest<T>(
  source: string,
  query: string,
  variables?: unknown
): Promise<{ data: T; rateLimited: boolean }> {
  const response = await request(source, { rawData: true })(query, variables)

  const remaining = Number(response.headers?.get("X-RateLimit-Remaining") ?? -1)
  const resetAt = response.headers?.get("X-RateLimit-Reset")

  if (remaining <= 5 && remaining >= 0) {
    console.warn(`Rate limit warning: ${remaining} requests remaining, resets at ${resetAt}`)
  }

  return {
    data: response.data as T,
    rateLimited: remaining === 0,
  }
}
```

## Raw data in direct mode

Raw data mode works identically in both proxy and direct modes. The response shape is always `{ status, headers, data }`:

```ts title="app/dashboard/page.tsx"
// Raw data works identically in direct mode
import { directRequest } from "@/lib/direct-request"

export default async function DashboardPage() {
  const response = await directRequest("myApi", { rawData: true })("stats:overview")

  // Same shape: { status, headers, data }
  const cacheStatus = response.headers?.get("X-Cache")

  return (
    <div>
      <p>Cache: {cacheStatus}</p>
      <pre>{JSON.stringify(response.data, null, 2)}</pre>
    </div>
  )
}
```

<Callout variant="tip" title="Type inference with rawData">
When `rawData: true` is set, TypeScript automatically infers the return type as `Promise<Partial<MethodKyResponse<T>>>` instead of `Promise<T>`. The `data` field inside the response retains the original method's response type.
</Callout>
